串口没有出现？

多数情况是数据线问题，请按顺序尝试：

  1. 换一根能让手机和电脑互传照片或文件的 USB 数据线；只能充电的线不会出现串口。
  2. 拔掉开发板，按住板上的 BOOT 键，再插入 USB；等待两秒后松开 BOOT，然后重新点击安装。
  3. 最后，关闭可能占用串口的软件，例如 Arduino IDE、PlatformIO 或串口调试工具。如果你不知道这些是什么，通常说明你没有打开它们，可以跳过这一步。

系统与驱动 macOS 无需手动安装驱动；Windows 10/11 联网时通常会自动安装。若设备管理器中出现两个 USB JTAG/serial debug unit，且“端口（COM 和 LPT）”下没有 USB 串行设备（COMx），说明驱动没有正确安装。 查看乐鑫官方驱动修复步骤
