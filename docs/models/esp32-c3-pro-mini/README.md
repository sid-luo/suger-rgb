# ESP32-C3 Pro Mini 主板保护壳

[English](README.en.md) · [返回详细教程](../../GUIDE.md)

原模型由 **[Mattia Carli](https://makerworld.com/zh/@MattiaCarli)** 制作，来源为 MakerWorld 的 [Case for ESP32-C3 PRO MINI ESP32-C3FH4](https://makerworld.com/zh/models/2008412-case-for-esp32-c3-pro-mini-esp32-c3fh4#profileId-2163305)。这是主板保护壳，不是项目首页 AI 效果图中的完整灯具外壳。

## 文件下载

| 文件 | 内容 | 适用情况 |
| --- | --- | --- |
| [原版 STL](Case_ESP32-C3_PRO_MINI_V01.stl) | 盒体和盖子位于同一个文件中 | 切片软件或打印平台支持在同一文件中处理两个零件 |
| [盒体 STL](Case_ESP32-C3_PRO_MINI_V01_Body.stl) | 单独的盒体 | 分别上传、打印两个零件 |
| [盖子 STL](Case_ESP32-C3_PRO_MINI_V01_Lid.stl) | 单独的盖子 | 与盒体配套使用 |

如果打印平台不接受一个文件中包含两个独立零件，请分别上传**盒体**和**盖子**，两件都需要打印。本项目在嘉立创上传组合文件时遇到不接受的情况，因此提供拆分版。

## 拆分说明

拆分版由 Suger RGB 项目维护者提供：只把原模型中的两个零件分到独立文件，并将各自的位置移到 X/Y 居中、底部 Z=0；没有缩放或修改外壳结构。原版文件仅统一了文件名，内容保持不变。

| 零件 | 外部尺寸（按毫米导入时） |
| --- | --- |
| 盒体 | 约 29.30 × 21.70 × 7.50 mm |
| 盖子 | 约 29.30 × 21.70 × 3.30 mm |

STL 本身不记录单位，导入时请核对上述尺寸。两个拆分文件都位于各自原点附近，同时导入切片软件时应作为独立对象排列，避免重叠。打印前请核对自己的主板尺寸和接口位置；文件几何检查不等于实际打印、装配验证。
