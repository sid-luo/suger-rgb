# Changelog

Suger RGB follows [Semantic Versioning](https://semver.org/). Dates use `YYYY-MM-DD`.

## [1.0.0] - 2026-09-17

Initial release:

- ESP32-C3 Pro Mini and 1–128 WS2812B pixels;
- five glucose color ranges with Nightscout trend effects;
- high-visibility effects below 3.3 mmol/L and at or above 15 mmol/L;
- ten-minute stale-data indication;
- bilingual captive setup page with connection validation and effect previews;
- BOOT long-press setup and connection reset;
- browser-based ESP32-C3 firmware installer;
- bilingual interactive browser demo for glucose colors, trends, and LED layouts;
- concise project overview plus separate Chinese and English step-by-step guides;
- setup HTTP server disabled during normal operation.
